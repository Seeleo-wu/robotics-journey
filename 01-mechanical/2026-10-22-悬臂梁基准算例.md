# 悬臂梁基准算例（Simulation 验证用）

日期：2026-10-22
目的：**建立一套"能对答案"的仿真验证流程**。以后每学一个新功能，都先用这个算例校一遍手。

---

## 一、模型

```
几何：100 × 20 × 5 mm 平板
材料：合金钢 Alloy Steel
      E  = 210,000 MPa
      σs = 620 MPa（屈服）
约束：一端 20×5 端面 固定
载荷：自由端 100 N，方向垂直于板面
```

---

## 二、手算（梁理论）

```
惯性矩    I   = b·h³/12 = 20 × 5³ / 12 = 208.33 mm⁴
弯矩      M   = F·L = 100 × 100 = 10,000 N·mm
最大挠度  δ   = F·L³/(3EI) = 100 × 100³ / (3 × 210000 × 208.33) = 0.762 mm
最大应力  σ   = M·c/I = 10000 × 2.5 / 208.33 = 120.0 MPa
安全系数  n   = 620 / 120 = 5.17
```

---

## 三、仿真结果（细网格，最终值）

| 项 | 手算 | Simulation | 误差 |
|---|---|---|---|
| 最大位移 | 0.762 mm | **0.7538 mm** | −1.1% |
| 最大 von Mises 应力 | 120.0 MPa | **119.4 MPa** | **−0.5%** |
| 安全系数 | 5.17 | **5.20** | +0.6% |

**结论：三项全部在 1.5% 以内，算例可信。**

---

## 四、为什么仿真值略小于手算（正常现象）

**两个原因，都不是错误：**

**① 端面全约束比理想固支更刚**

梁理论假设"固定端可以自由收缩"，但 SW 把端面的**所有节点三个方向都锁死**，
连泊松收缩都被禁止了 → 根部比理论更硬 → 位移偏小。

**② 应力平均化**

图例最大值是单元值或节点平均后的结果，理论上的边缘峰值被节点平滑掉了 → 应力偏小。

> **规律：这类静力算例，仿真结果落在手算的 95%~100% 之间是正常的。超过 100% 才要警惕。**

---

## 五、网格收敛性验证（已完成）

| | 粗网格 | 细网格 | 手算 | 细网格误差 |
|---|---|---|---|---|
| 最大位移 | 0.7532 mm | **0.7538 mm** | 0.762 | −1.1% |
| 最大应力 | 117.1 MPa | **119.4 MPa** | 120.0 | −0.5% |

```
位移变化  0.7532 → 0.7538   差 +0.08%   ← 已完全收敛
应力变化  117.1  → 119.4    差 +1.9%    ← 收敛（<5%）
```

**结论：网格收敛，0.7538 / 119.4 可信。**

**两条规律：**

1. **位移比应力收敛得快。** 位移是整体量，粗网格也能算准；应力是局部量，需要更细网格才能逼近峰值。
2. **加密网格后应力往手算值靠拢**（117.1 → 119.4，手算 120）。这是 FEA 的正常行为——网格越粗，模型越"硬"，结果越偏小。

**判断标准（以后照这个判）：**

| 加密后变化 | 判断 |
|---|---|
| < 5% | 收敛，结果可信 |
| 5% ~ 10% | 勉强，建议再密一档 |
| > 10% | 没收敛，粗网格值不能用 |

## 六、允许误差带（以后照这个判）

| 你算出的 / 手算 | 判断 | 怎么办 |
|---|---|---|
| 0.95 ~ 1.05 | ✅ **对上了** | 可以做下一步 |
| 0.5 ~ 0.95，或 1.05 ~ 2 | ⚠️ 可疑 | 查网格、查约束面数 |
| 差 10 倍左右 | ❌ 单位错 | 查材料单位是 MPa 还是 Pa |
| 差 100 倍以上 | ❌ 边界条件错 | 查夹具和载荷方向 |
| 和"另一种受力"的解析解吻合 | ❌ **加载方向错** | 见下面第七节 |

## 七、踩过的坑：力方向

**错误做法：**
```
力作用在端面 + 方向选「垂直于面」
→ 垂直于【端面】= 沿轴向 = 拉伸
→ 位移 0.000475 mm，应力 1.381 MPa
```

**正确做法：**
```
力作用在端面 + 方向选「选定的方向」+ 点【上表面】
→ 作用于端面、方向垂直板面 = 悬臂弯曲
→ 位移 0.7538 mm，应力 119.4 MPa（大 1587 倍）
```

**反查方法（记下来，这是关键技能）**

当数值差得离谱时，**用"错误假设"的解析解去验**：

```
如果是轴向拉伸：
  σ = F/A = 100/(20×5) = 1.0 MPa      ← 软件给 1.381（含应力集中）✓
  δ = FL/(EA) = 100×100/(210000×100) = 0.000476 mm  ← 软件给 0.000475 ✓
两个数都精确吻合 → 确认是轴向，不是软件错
```

**这条方法的普适性：数值对不上时，先问"我这个数其实在描述什么物理现象"。**

## 八、云图的视觉判据

| 云图形状 | 说明 |
|---|---|
| **一头红一头蓝，沿长度渐变** | ✅ 弯曲（正确） |
| **整片均匀一个颜色** | ❌ 拉伸（力方向错） |
| 最大应力集中在约束边缘一小点，且随网格加密不断变大 | 应力奇异，不可信 |

**看形状比读数字快。先用眼睛判断受力形式对不对，再看数值。**

**正确悬臂梁的两个特征：**

```
位移云图：自由端深红（最大），固定端深蓝（零），沿长度渐变
应力云图：固定端上表面红（受拉最大），固定端下表面蓝，自由端整体蓝
```

## 九、三个结果指标的用途

| 指标 | 单位 | 判断什么 | 什么时候看 |
|---|---|---|---|
| **应力** | MPa | 够不够强（对比屈服强度） | 每次都看 |
| **位移** | mm | 够不够刚（会不会晃、精度够不够） | 每次 都看 |
| **应变** | 无量纲（με） | 只在非线性、塑性、实验对比时用 | 线弹性分析不用看 |

**交叉验证：** `ε = σ/E = 119.4 / 210000 = 5.69e-4 = 569 με`
去应变图上核对，最大值应该在 5.7e-4 左右。三个数自洽，说明材料设置没错。
