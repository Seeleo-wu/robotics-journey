## 四、理论值

| 项 | 理论值 | 来源 |
|---|---|---|
| 滑块销孔行程 | **100 mm** | 2r = 2 × 50 |
| 运动周期 | **1 s** | 60 RPM |
| 最大速度 | **≈ 330 mm/s** | 见下 |
| 最大加速度 | **≈ 2630 mm/s²** | ω²r(1 + r/l)，出现在 θ = 0° |

**速度极值的正确推导（把之前记错的 366 纠正过来）**

```
x(θ) = r·cosθ + √(l² − r²sin²θ)
v(θ) = −ωr·[ sinθ + (r/2l)·sin2θ ]

求极值：cosθ + (r/l)·cos2θ = 0
r/l = 1/3 时：2cos²θ + 3cosθ − 1 = 0 → cosθ = 0.2808 → θ ≈ 74°

v_max = ωr × 1.0496 = 6.2832 × 50 × 1.0496 = 329.8 mm/s
```

**注意**：ωr(1 + r/(2l)) = 366 是错的（那是加速度近似式），不要再用。

**一个值得记的规律**：**最大加速度出现在速度为零的位置**（θ = 0°，即行程最远端）。换向瞬间冲击最大。

## 五、间隙晃动仿真（进阶）

**参数**

```
滑轨宽      3.0 mm
滑块槽宽    3.5 mm
单边间隙    0.25 mm
```

**做法**：滑块与导轨之间**不加任何配合**，全部交给接触；重力开启，让滑块压在导轨上。

**结果**：晃动现象做出来了，**但肉眼不明显**。

**为什么正常**

```
0.5 mm 间隙 ÷ 行程 100 mm = 0.5%
最大偏转角 ≈ atan(0.5 / 40) = 0.72°（40 是滑块槽沿轨方向的长度）
传递到末端的位置误差 ≈ 0.25 mm
```

**结论：这 0.5 mm 是「装配余量」，不是「运动精度瓶颈」。**

## 六、两条踩出来的经验（本文件最有价值的部分）

**① 一个自由度只能由一种机制负责**

```
错误：同一个自由度既加配合（说「你必须在正中间」）
      又交给接触（说「你撞到我了我推你」）
→ 求解器两边都满足不了 → 发散 → 零件乱飞
```

| 机制 | 负责什么 |
|---|---|
| 配合 | 定位（方向关系） |
| 限制配合（高级配合→距离/角度） | 行程限位 |
| 接触 | 只处理间隙、碰撞力 |

**② 运动算例玩废了就删掉重建**

```
仿真模型和代码一样：在脏模型上打补丁只会越补越乱。
右键运动算例 → 删除 → 新建，30 秒的事，比排查一小时划算。
```
