# W01 · 逆向三问（对象：指甲钳）

日期：2026-10-20
耗时：约 45 分钟
对象：普通不锈钢指甲钳（如图）

---

## 一、结构观察（原始回答 + 修正）

### 1. 销轴位置
**我的回答：** 靠前，倒着卡入。销钉卡住上面压杆，压杆的作用力点应在前面，否则杠杆会导致很难减下去。

**修正：** 销轴不是"卡子"，它是**支点（铰链 / pivot）**，整个压板绕它转动。后半句方向对：**支点位置决定两个力臂，同时它承受全部反作用力**，所以必须是实心钢轴。

### 2. 上压板（销轴 → 拇指）
**我的回答：** 20~30 mm
**实测：** **A = 38~40 mm**

### 3. 斜舌片接触点
**我的回答：** 顶在刀片前半部分

**修正：** 位置本身不是重点。关键是**它离刀片自己的支点（尾部铆钉）多远**——那段才是刀片的阻力臂。

### 4. 刃口形状
**我的回答：** 弧形，为贴合指甲；弧度小于指甲否则剪不了，太大则要频繁变更方向。

**评价：** 全组最好的一题。这是"参数—体验"的双约束推理：**曲率太小剪不动，曲率太大要反复转方向。**

### 5. 回弹机构
**我的回答：** 靠刀片自己的弹性势能。两片刀片尾部固定在一起，是类似销钉但**不可拆卸**的结构，不知道怎么称呼。

**术语补充：**
| 我的描述 | 正名 |
|---|---|
| 不可拆的销钉 | **铆钉**（rivet），工艺叫**铆接** |
| 刀片自身弹性 | **板弹簧 / 簧片**（leaf spring） |
| 始终想张开的状态 | **预应力 / 预紧**（preload） |
| 整个结构 | **弹性夹持机构**（spring-loaded jaws） |

**设计价值：** 省掉一根独立弹簧 = 少一个零件、少一道装配、少一个失效点。这是 **DFM（Design for Manufacturing）** 的经典手法。

## 二、三问

### 6. 销轴直径 ≈ 3 mm，为什么不是一半或两倍？
**我的回答：** 太细容易掉，太粗没必要，消耗原料。

**修正：** 真实原因排序 → ① **标准件系列**（销轴只有 2/2.5/3/4 mm）② **刚度**（太细会弯）③ **配合与耐磨**（细了接触面积小，晃得快）④ 空间/重量。**材料成本排最后。**
> 小零件的铁律：**先看标准件有没有，再算强度。**

### 7. 上压板为什么这么长？
**我的回答：** 省力，否则要更使劲，导致剪指甲不精准。

**补充：** 杠杆**不创造能量**——**省力 N 倍，行程也变成 N 倍**。压板越长越省力，但手指要按得更深。

### 8. 压板长度减半会怎样？
**我的回答：** 剪指甲不精准。

**修正（正确答案）：** **要两倍力 + 行程减半 → 手感变"硬"**。人靠**位移**控制精度，不靠力；位移变小了，就失去反馈 → 剪不准。
> 这就是"手感"的物理本质。

### 9. 销轴直径减半会怎样？
**我的回答：** 装配容易掉，不易加工卡槽。

**修正（本组最重要的一题）：**
| 直径减半 | 变化 |
|---|---|
| 截面积 ∝ d² | 剪切强度 **只剩 1/4** |
| 惯性矩 ∝ d⁴ | 抗弯刚度 **只剩 1/16** |

**主要后果是"弯"和"晃"，不是"掉"。**
> **口诀：直径减半 → 强度 1/4，刚度 1/16。**

### 10. 刃口厚度减半会怎样？
**我的回答：** 容易崩刀。（并猜"这题基本没影响"，理由：指甲硬度没那么大）

**评价：✅ 猜对了，理由也对。**
指甲剪切强度仅 20~40 MPa（角蛋白，莫氏约 2.5）。**刃口厚度由"耐磨寿命"决定，不是强度决定。**
> 规律：**越软的被切材料，刃口尺寸越由寿命决定。**

### 11. 剪一片指甲，刃口需要多大力？
**我的回答：** 50 N（完全没概念）

**给了估算方法：**
```
切断力 = 剪切强度 × 剪切面积
       = 30 MPa × (0.5 mm 厚 × 8 mm 宽)
       = 120 N   ← 这是上限
```
**实际远低于此**：指甲是**渐进开裂**（先压缺口再裂），峰值力约 30–60 N。

### 12. 拇指上实际出多大力？
**我的回答：** 10 N（猜）

**结论：必须实测。** 见下方"待补实验"。

## 三、杠杆测量

| 项 | 值 |
|---|---|
| 支点 | 销轴（前端，靠近刃口） |
| 力臂 A：销轴 → 拇指 | **38 ~ 40 mm** |
| 我量的 B：销轴 → 刃口 | 4 ~ 5 mm |
| 算出的比值 | 8 ~ 9 |

**⚠️ 这个 8~9 不能直接用。**
"销轴 → 刃口"在力学上**不属于任何一根杠杆的臂**。力走了两跳：

```
拇指 → 压板绕销轴转 → 斜舌片压刀片 → 刀片绕尾部铆钉转 → 刃口
        杠杆①                          杠杆②
```

**正确的量法：**
- 杠杆① 力臂 = 销轴 → 拇指（40 mm）
- 杠杆① 阻力臂 = 销轴 → **斜舌片接触点**（未量，估计 8–12 mm）
- 杠杆② 力臂 = 尾部铆钉 → 斜舌片接触点
- 杠杆② 阻力臂 = 尾部铆钉 → 刃口

**总传动比 = 各级相乘。** 第二级是**费力杠杆**（≈0.7），因为舌片顶得靠前，为的是**放大行程**。
估算总比 ≈ **2.5 ~ 4**。

## 四、待补实验（下次做，5 分钟）

**用厨房秤量出拇指力，一锤定音：**

1. 指甲钳平放在厨房秤上，归零
2. 手指按压板，像真剪指甲那样用力
3. 读最大值（kg）→ × 9.8 = 拇指力（N）
4. 总传动比 = 刃口力(30~60 N) ÷ 拇指力

| 称出 | 总传动比 | 结论 |
|---|---|---|
| 10 N | 3–6 倍 | 我的估算对 |
| 5 N | 6–12 倍 | 你的直觉对 |

## 五、今天真正带走的五条

```
1. 支点决定杠杆比，同时承受全部反力
2. 强度问"会不会断"，刚度问"会不会变形"；一个是 A，一个是 I
3. 直径减半 → 强度 1/4，刚度 1/16（d² vs d⁴）
4. 力臂要沿力的传递路径量，不是两点直线距离
5. 复合杠杆总传动比 = 各级相乘；省力必然费行程
```
