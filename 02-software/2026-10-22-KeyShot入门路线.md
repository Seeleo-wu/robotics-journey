# KeyShot Studio 2025 入门路线（工业设计方向 · 每天 30 分钟 · 7 天出第一张成品图）

**怎么用这份文件**：每天只做当天那一格，做完在表里打勾。卡住就把"卡在哪"写进当天日志（`01-日志/YYYY-MM-DD.md`）。不要跳天，也别提前看第 5 天。

**目标物**：一个工业设计小件（支架 / 充电宝 / 台灯底座这类），7 天后输出一张 1600–1920px 的 PNG，有地面阴影 + 一点景深，缩到手机上看着"像照片"。

## 实战对象：HERO.STEP（上交 RoboMaster 英雄机器人）

文件：`D:\~LeoWu\学习资料\03-软件\Keyshot\HERO.STEP`

**扫出来的硬事实（2026-10-22 实测，不是猜的）**
- 176.2 MB，STEP AP214，SolidWorks 2020 导出（2021-08-27 创建），坐标单位 **mm**
- **468 个实体**（MANIFOLD_SOLID_BREP），另有 **60 个无厚度曲面**（OPEN_SHELL）
- 200 个 B-rep 装配表示 → Scene Tree 里应该是**带层级的装配树**，不是 468 个平铺零件

**导入对话框只改两处**
1. Position 段勾 **Snap to Ground** —— 机器人直接坐在网格地面上，省掉手动对齐底盘。
2. Geometry 段 **Tessellation Quality 保持默认 0.2**，千万别为了"更圆滑"往高调，468 个实体会等到天亮。这个格式支持的话把 **Accurate Tessellation** 勾上。

其余全部默认：Center Geometry 勾着（模型居中）、Up Orientation 保持 Y Up（如果进来是躺倒的再改）。

**版本注意（2026-10-22 已确认）**：本机是 **KeyShot Studio 2025.1 Professional，就是 Pro 版**。所以 `Import NURBS Data`、`Model Set`、`Region` 渲染全都可用，不用绕。STEP 的单位写在文件里，不需要像 .stl / .obj 那样手动选 Geometry Unit。

**心态（这条最重要）**：468 个零件 ≠ 468 个要处理的东西。产品图只拍得到外壳、轮子、云台、发射管这些外露件，内部的电机、螺丝、线束**根本不用管**——不用删、不用赋材质、不用改名。只有它明显拖慢实时视图，才值得去隐藏。

**耗时预期（已实测，2026-10-22）**：本机导入 **不到 20 秒**。我原先那句"要等几分钟、别以为卡死了"作废——这台机器吃得下这个体量。以后导入别的装配体，20 秒没动静再开始怀疑。

**已知坑**：那 60 个无厚度曲面进 KeyShot 会变成"纸片"，可能穿帮或受光不对称。视图里看到莫名其妙的薄片，去 Scene Tree 的搜索框里找出来隐藏。

## 界面在哪（2026-10-22 实拍确认）

窗口打开时是 **Startup 工作区**：一块干净的画布，所有面板都收起来了。找不到按钮不是不会用，是布局把它藏了。三个入口记住就够：

1. **顶部菜单栏**：文件 / 编辑 / 环境 / 照明 / 相机 / 图像 / 渲染 / 工具 / 查看 / 窗口 / 帮助。所有命令的最终入口，渲染参数、环境、相机都能从这进。
2. **Ribbon 区**：现在被折叠成一条，只剩图标——工作区 / GPU 使用量 / 暂停 / 性能模式 / GPU / 去噪 / 视角 / 工具。**双击这一条的空白处**（或点右端的折叠箭头）展开完整功能区。
3. **底部工具条**：导入 / 库 / 项目 / 动画 / 导出模式 / KeyShotXR / VR / 渲染 / 截屏。

**场景树到底在哪（2026-10-22 更正）**：点底部「项目」后，面板出现在**窗口右侧**（不是左边，我第一次说错了）。那个面板顶上有一排标签：**场景 / 材质 / 相机 / 环境 / 照明 / 图像**。

- **场景树 = 「场景」标签下的那串零件列表**（就是名字乱码那一列）。
- 「材质」标签显示的是**当前选中零件**的材质参数（名称、类型、颜色、粗糙度）和材质球预览。要改一个零件的材质，得先在场景树或视图里选中它。

**每天开工先点三下**：底部「项目」→ 右侧点「场景」；底部「库」→ 材质 / 环境库；底部「渲染」→ 出图。

**关于那圈灰**：实时视图里的矩形是**画面边界**，比例等于渲染分辨率，成品图只渲染框内像素，**灰色永远不会出现在你的图里**。框显得偏小是因为视图缩放停在 100%（Ribbon 上那个下拉）——把它切到"适合窗口"，或者直接把分辨率改成接近窗口的比例。

**STEP 把颜色带进来了**：车身上的蓝、黄、粉是 SolidWorks 里的外观色，没丢。D2 学材质可以在这基础上改，不用从一片灰开始。

## 零件名为什么是乱码（2026-10-22 已定位）

场景树里 `·ÉÆÂµ¼ÂÖ¹Ì¶¨°åFinVer` 这种东西不是导入失败，是**编码不匹配**：

- 我扫了 HERO.STEP：**222 个零件/子装配名**，里面有 **11160 个高位字节**，而且 **零个**标准 STEP Unicode 转义（`\X2\...\X0\`）。
- 结论：SolidWorks 导出时把中文按 **GBK 字节**直接写进了 STEP，而 KeyShot 按别的编码读，于是全变成乱码。
- 软件里**没有"导入编码"这个选项**，所以场景树里修不掉，别在这上面耗。

**三条出路**
1. **对照表**（已经在用）：`HERO零件名对照表.md`，我把 222 条全部 GBK 解码列出来了，乱码能查到真名。
2. **就地重命名**：场景树右键 Rename，把常打交道的十几个件改成中文代号。改完存 `.bip`，以后都认。
3. **改源头**：SolidWorks 里把零件名改成英文/拼音再导 STEP。最彻底，但要动原装配体。

**能认的几个例子**：`飞轮导轨固定板FinVer`、`保险杠组FinVer`、`3508电机`、`19mm铝柱FinVer`、`6020摇臂 1.0FinVer`、`陀螺仪垫圈`。

## 本机实测环境（2026-10-22）

| 项目 | 实测结果 | 对计划的影响 |
|---|---|---|
| HERO.STEP 导入（468 实体 / 176 MB） | **不到 20 秒** | 可以放心反复重导，场景搞坏了就重来，不用心疼 |
| GPU Mode | **可用（Ribbon 图标亮）** | 渲染走显卡，D6 那天不用干等，能多出几版对比挑一张 |

**GPU 模式的三条规矩**
1. 第一次切到 GPU 要重建加速结构，可能卡十几秒，那不是崩了。
2. GPU 模式对少数特性有限制（位移、雾、部分程序纹理这一类）。某个效果打开后毫无反应，先切回 CPU 模式验一次，再判断是不是自己设错。
3. 显存吃满会直接报错或闪退。切 GPU 后若崩，先把分辨率降一半试，确认是显存问题再考虑隐藏内部件。

## D1　界面 + 第一张图（30 分钟）

**目标**：不求好看，只求"这软件我能驱动它出图"。

0–5 分钟　认清三块骨架
- 上方 **Ribbon 功能区**：Workspaces（工作区/明暗主题）、Pause、Performance Mode、GPU Mode、Denoise、Region、Render。
- 两侧可停靠的**面板**：Scene Tree（场景树，模型、材质、相机、灯光、环境全挂在这）、Library（资源库：Materials / Environments / Textures / Backplates / Models）。
- 中间 **Real-time View**：所有操作即时反馈，这就是你的"取景器"。
- 右下 **Render** 面板。

5–10 分钟　3 分钟摸鼠标手感
在实时视图里把左键拖、中键拖、右键拖、滚轮各试一遍，记下你这台机器上哪个是旋转、哪个是平移、哪个是缩放。把这句写进今天日志——以后每天都要用。

10–20 分钟　导入模型
把 `.step/.stp`（或 `.obj/.fbx/.stl`）直接拖进 KeyShot 窗口，或 File > Import。导入对话框先全部默认，直接 Next / OK。
- 建模软件里已经有的装配体，进 KeyShot 会拆成一堆 part，这是正常的，不用整理。
- 模型跑到视野外：用 Ribbon 或右键菜单里的 Fit，或者把滚轮缩到最小再慢慢滚回来。

20–27 分钟　拖第一个材质
Library > Materials 搜 "plastic"，随便拖一个塑料到模型上，颜色在右侧 Material 面板里改。

> **HERO.STEP 版走法**：先在 Scene Tree 里 Ctrl+A 全选，再把材质拖到视图里的模型上——会一次赋给所有选中件。468 个体量的模型，这是唯一省事的开局。默认灰塑料至少比 KeyShot 的裸白模好看，先把"有图"这件事拿到手，D2 再分零件精修。

27–30 分钟　出图
Render 对话框（Ribbon 的 Render 按钮，或 Ctrl+P）：Resolution 填 800×600，Quality 选 Maximum Samples 填 32，点 Render。

**验收**：输出目录里出现一张 png，打开不是黑的。
**省时间**：Ribbon 上的 GPU Mode 图标只要不灰就点开，比 CPU 模式快很多。图标灰了 = 显卡驱动要更新。

**✅ D1 已完成（2026-10-22 11:33）**
- 成品：`D:\Keyshot\Renderings\Test1.1.jpg`，1920×1200，1.0 MB
- 实际用时远少于 30 分钟（GPU 渲染几秒一张）
- 画面状态：形体完整、有反射、有软阴影，STEP 带来的蓝 / 黄 / 粉配色都在

**最大的疏漏：场景没存盘。** 标题栏还是 `untitled.bip` —— KeyShot 一崩，今晚所有调整全丢。**以后每出一条能看的图，第一件事 Ctrl+S。**

**这一版暴露的三个问题（按影响排序，正好对应 D2–D4）**
1. **全机一片白、没有材质层次**：CAD 带进来的外观大多是"白 / 漫反射"，看不出是塑料还是铝。→ D2 解决。
2. **主体偏左下，前面装甲板被画面边缘切掉**：构图没留边。→ 先拉远一点让主体占 60–70%，D4 再精修。
3. **阴影太弱、地面读不出来，白件又贴白背景**：形体全靠环境光撑着，没有一道硬高光。→ D3 解决。

## D2　材质（30 分钟）

只学三种，别的先不碰。

| 材质类型 | 要动的参数 | 记住的感觉 |
|---|---|---|
| Plastic（塑料） | Color、Roughness | Roughness 0 = 亮面注塑；0.2–0.4 = 磨砂；0.6+ = 哑光喷涂 |
| Metal（金属） | Color、Roughness | 颜色决定铝 / 不锈钢 / 黄铜；Roughness 决定抛光还是拉丝 |
| Glass / Solid Glass | Color（极淡）、Roughness=0 | 折射率保持 1.5 别乱动，玻璃靠背景折射才像玻璃 |

**动作**
1. 场景里做三个球（或直接拿你模型的不同零件），分别拖上三种材质。
2. 每种材质只改 Color 和 Roughness 两个滑块，各出 3 张截图对比。
3. 记住一句话：**产品渲染 90% 的材质问题，是 Roughness 没调对，而不是材质类型选错。**

**验收**：三张图并排，一眼分得出塑料、金属、玻璃。
**先不碰**：贴图、Bump、RealCloth、液体、宝石。D7 之后再说。

## D3　打光（30 分钟，全周最值钱的一天）

KeyShot 的默认打法不是"自己摆一堆灯"，而是 **HDRI 环境光**。

1. Library > Environments，拖一个 Studio 系的环境进来（名字里带 Studio / Softbox / Product 的都行）。模型立刻有光。
2. 打开 Environment 面板，找到 **Rotation** 滑块，慢慢转 —— 同一个 HDRI，高光位置转 30°，高级感完全不一样。这是新手最容易漏掉的一个滑块，反复玩 10 分钟。
3. 加一道**硬高光**：加一个 Area Light（或点光）放在模型侧后方 45°，专治金属边缘没"亮筋"。
4. 加 **Ground Plane**：材质给浅灰 Plastic 或 Diffuse，**别用纯白**，白地面会把阴影吃掉。

**验收**：转一圈 Rotation，你能指出来"高光亮在这个位置最好看"。
**口诀**：商业产品图 = 一个柔和 HDRI + 一道硬高光 + 一块不抢戏的地面。

## D4　相机（30 分钟）

1. 调好视角后 **Add Camera** 把视角存下来，之后所有渲染都用它。
2. **Focal Length（焦距）**：产品照常用 50–85mm，变形小；24–35mm 广角会让东西"变壮"，慎用。
3. **Depth of Field（景深）**：打开，焦点吸到主体上；F-stop 数字越小背景越糊。产品图常给 f/8–f/16，整机清楚、只虚背景。
4. 竖直校正（两点透视 / Keystone 那类选项）：平视看产品时把竖线拉直，别让产品"倒"下去。
5. 构图：主体占画幅 60–70%，45° 三分之二视角最像产品照，别死居中。

**验收**：相机存住了，切别的视角还能一键切回来。

## D5　图像（30 分钟）

Image 面板，按顺序只用这四个：

1. **Exposure**：整体偏暗就 +0.3 一档一档试；偏亮就减。只动这一个就能解决一半"看着不对"。
2. **Gamma**：画面发灰时微调。
3. **Image Style**：先 Basic；Denoise 打开；Bloom 给 0.1–0.2 让高光微微发光；Vignette 别超过 0.2。
4. **Background**：要白底就换纯色 / Backplate；要场景感就换一张带背景的 HDRI。

**验收**：手机上看这图，不觉得"假"。

## D6　正式渲染（30 分钟）

1. **Resolution**：1920×1440（或长边 2000）。
2. **Quality**：Maximum Samples 填 **128**。GPU 模式下 128 + Denoise 的产品图已经很干净，别无脑上 256/512——多花的时间换不到看得见的差别。赶时间就用 Maximum Time 填 1 分钟先看构图。
3. **Denoise** 勾上。Ribbon 上的 Denoise 按钮状态跟随 Image Style，锁住了会点不动。
4. **Output**：PNG + Alpha（要抠图/放网页）；TIFF 16-bit（要进 PS 调色）；需要分通道再勾 Clown / Object ID / Depth。
5. 点 Render 等结果。本机 GPU 模式实测：800×600 / 32 samples 几秒钟出图；1920×1440 / 128 samples 预计一两分钟（D6 那天记下真实数字补进本节）。命名 `项目名_视角_v1.png`。

**验收**：有一张 1920px、没明显噪点的图。把 D1 第一张和这张并排看——差距就是这 6 天的全部内容。

## D7　沉淀（30 分钟）

把这周调好的东西存成预设，下次省 30 分钟：

1. 材质 → 加入 Library 的 Favorites（或 Save as `.mtl`）。
2. 环境 → 存成预设 / 加入 Favorites。
3. 渲染 → Render 面板里的 Quality 存成自定义预设。
4. 布局 → Ribbon > Workspaces > Save Workspace，把面板位置固定住。
5. 写日志：这周哪一步最费时间？把它变成下次的"直接跳过"。

## 速查卡（打印贴屏幕旁边）

- **拖动时满屏噪点、停手几秒变干净 = 正常**。KeyShot 是渐进式光追：拖动时只算极低采样保证跟手，停手后样本不断累加把噪点平均掉，最后 Denoise 收尾。噪点消失的快慢，就是你出图速度快慢。
- 停手很久噪点还在：看 Ribbon 的「暂停」是不是被按了，或者场景里有特别暗的光源在死磕（暗部需要更多采样才收敛）。
- 卡住了先看三处：Scene Tree 里有没有东西 / 材质有没有拖上去 / Environment 是不是空的。
- 图全黑：Environment 没加载，或相机卡在模型内部。
- 图全白过曝：Exposure 太高，或地面是纯白。
- 金属发黑：金属只反射环境，没 HDRI 就是黑的。
- 玻璃像塑料：Roughness 不是 0，或背后没有东西可折射。
- 渲染太慢：开 Performance Mode、开 GPU Mode，samples 先降到 32 只看构图。
