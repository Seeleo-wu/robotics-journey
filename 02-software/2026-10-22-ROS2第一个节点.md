## 二、代码

```python
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist


class Spinner(Node):
    def __init__(self):
        super().__init__('spinner')
        self.pub = self.create_publisher(Twist, '/turtle1/cmd_vel', 10)
        self.timer = self.create_timer(0.1, self.tick)
        self.n = 0

    def tick(self):
        msg = Twist()
        msg.linear.x = 2.0
        msg.angular.z = 1.8 if self.n < 25 else -1.8
        self.pub.publish(msg)
        self.n += 1


def main():
    rclpy.init()
    node = Spinner()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## 六、顺手搞清的五个概念

| 概念 | 一句话 |
|---|---|
| **node 节点** | 一个正在运行的 ROS2 程序。`ros2 node list` 能看到它 |
| **topic 话题** | 广播频道。发布者往里发，订阅者从里读，双方互不认识 |
| **package 包** | 一个功能单元，必须有 `package.xml`。ROS2 靠它认出这是个合法包 |
| **python3** | 显式指定 Python 第 3 版（2 与 3 语法不兼容，2 已于 2020 年停止维护） |
| **turtlesim** | turtle + sim(ulation)，乌龟模拟器。1966 年 Logo 海龟绘图的教学传统 |

**turtlesim 里有什么**

```bash
ros2 pkg list                     # 我这台装了 287 个包
ros2 pkg executables turtlesim    # 这个包里能跑的程序
```

## 七、这次暴露的缺口

**会 `import`，不会 `class`。**

另外几个没见过的语法：

| 语法 | 一句话 |
|---|---|
| `class Spinner(Node):` | 定义类，继承 Node |
| `self` | 「这个对象自己」，每个方法第一个参数 |
| `__init__` | 初始化方法，创建对象时自动执行 |
| `A if 条件 else B` | 三元表达式，等价于 if/else 赋值 |
| `try / except` | 异常处理，让 Ctrl+C 时安静退出 |
| `if __name__ == '__main__':` | 只有直接运行才执行 main() |
