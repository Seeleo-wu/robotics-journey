## 一、材质库怎么"一次赋给一批"（5 分钟）

末级操作只有两步：**先选中，再从材质库把材质拖到视图里的模型上**。

| 想选什么 | 怎么选 |
|---|---|
| 全部 | 场景树里 Ctrl+A |
| 零散的几个 | Ctrl + 逐个点 |
| 连续一片 | 点第一个，Shift + 点最后一个 |
| 名字里带关键字的（如 3508） | 场景树上面的**搜索框**输入关键字，列表会过滤 |

选中之后，右侧「**材质**」标签里会出现：材质名称 / 类型 / Color / Roughness / 材质球预览。
改参数就在这里改——**改的是"当前选中的那些件"**，所以选错了全盘都错，改完先看材质球。

> 零件名是乱码没关系：`HERO零件名对照表.md` 里有 222 条 GBK 解码结果，
> 也可以在场景树右键 **Rename** 把常打交道的十几个件改成中文代号，然后存进 `.bip`。

## 二、三种材质，每种只动两个滑块（15 分钟）

| 材质类型 | 一定要动的 | 别乱动的 | 记住的感觉 |
|---|---|---|---|
| **Plastic** | Color、Roughness | — | Roughness 决定"注塑 vs 喷涂" |
| **Metal** | Color、Roughness | — | Color 决定铝 / 不锈钢 / 黄铜，Roughness 决定抛光还是拉丝 |
| **Glass / Solid Glass** | Color（调到极淡）、Roughness = 0 | **IOR 保持 1.5** | 玻璃靠"背后的东西被折射"才像玻璃 |

**Roughness 的视觉判据（本课最值钱的一张表）**

| Roughness | 眼睛看到的样子 | 典型用途 |
|---|---|---|
| 0 | 镜面，能看清反射物的轮廓 | 抛光件、亮面注塑 |
| 0.1 – 0.2 | 高光小而锐 | **产品图最常驻的"高级感"区间** |
| 0.2 – 0.4 | 磨砂、细颗粒 | 工程塑料、阳极氧化铝 |
| 0.5 – 0.7 | 哑光 | 涂装外壳 |
| 0.8 以上 | 几乎没有高光 | 粉笔、铸铁、橡胶 |

> **产品渲染 90% 的材质问题，是 Roughness 没调对，而不是材质类型选错。**
> 拖完材质觉得"不像"，先动 Roughness，别急着换材质类型。

**动作**：挑三个明显不同的件，分别赋三种材质，每种只改 Color 和 Roughness，各存一张截图。
**验收**：三张图并排，一眼分得出塑料 / 金属 / 玻璃。

## 三、HERO 上的分类法（10 分钟）——用三个问题分，别去猜每个件的真实材质

| 问自己 | 是 → 赋什么 |
|---|---|
| 它是钣金 / 机加工件（有棱有角、有孔、有倒角）吗？ | **Metal**。铝→Color 亮灰；钢→Color 偏冷灰；黄铜→偏黄 |
| 它是注塑壳 / 3D 打印件（圆润、大平面、外壳）吗？ | **Plastic**。壳体常用 Roughness 0.2–0.4 |
| 它明显是透镜、灯罩、亚克力板吗？ | **Glass / Solid Glass**，或透明 Plastic |
| 它看着像铝但颜色很深、没有镜面感？ | **阳极氧化铝** = Metal + 深灰 Color + Roughness 0.35–0.45（RM 车上最常见的状态） |

**RM 车上的高频件起手参数**

| 件 | 材质 | 起手参数 |
|---|---|---|
| 电机外壳（如 3508电机） | Metal | Color 浅灰、Roughness 0.3（压铸铝 + 喷涂） |
| 铝柱（如 19mm铝柱FinVer） | Metal | Color 稍亮、Roughness 0.2（拉丝感） |
| 摇臂 / 导轨固定板 / 碳板 | Plastic 哑光黑，或 Carbon Fiber | Color 近黑、Roughness 0.35 |

> 这些是**起手建议，不是标准答案**。判断依据永远是实物照片：找几张 HERO 的赛场照片对着看，
> 照片里亮得发白的地方就是金属高光，灰而均匀的地方就是塑料。

## 四、自查四条（3 分钟）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 金属一团黑 | 金属**只反射环境**，环境里没什么可反射 | 先随便拖一个 Studio 环境（这是 D3 的正题，今天先拿它救场） |
| 玻璃像塑料 | Roughness 不是 0，或背后是空背景没东西可折射 | Roughness 归零，背后加个东西 |
| 全白过曝 | Exposure 太高，或地面纯白吃掉了阴影 | 减 Exposure，地面换浅灰 |
| 拖动时满屏噪点 | 正常现象（渐进式光追） | 松手等几秒 |
