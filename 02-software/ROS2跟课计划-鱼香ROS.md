## 五、当前这道题（阶段0 的配套练习）

**题目**：把 `~/Python_demo/hello_world.py` 变成一个真正的 ROS2 功能包。

**验收标准（四条全过才算完成）**
1. `colcon build` 无报错，`source install/setup.bash` 之后 `ros2 pkg list | grep <你的包名>` 能查到
2. `ros2 run <包名> <入口名>` 能打印 `Hello, World!`
3. `package.xml` 里的 name / version / description / maintainer 四项是你自己改过的，不是模板默认值
4. `ros2 pkg executables <包名>` 能列出你的入口名
