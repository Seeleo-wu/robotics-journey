# 2026-10-20 · WSL 安装踩坑记录

> 目的：不是记"我装成功了"，是记"下次再遇到我怎么 3 分钟解决"。
> 环境：Windows 10.0.26100 / WSL 3.0.3 / Ubuntu 24.04.5 / 装到 D:\WSL

---

## 坑 1：命令打错（有空格）

```
错： wsl --install -d Ubuntu -24.04
对： wsl --install -d Ubuntu-24.04
```

**现象：** 报"无法与服务器建立连接"
**原因：** 空格让 WSL 把 `-24.04` 当成另一个参数，于是去找一个叫 `Ubuntu` 的包 → 联网失败
**教训：** 报网络错时，先检查命令本身有没有打错

---

## 坑 2：WSL 的 Windows 功能没启用

**现象：** `wsl --version` / `wsl --status` 都报"必须先安装 Linux 的 Windows 子系统"
**解决：** 管理员 PowerShell 执行两条 DISM，然后**重启**

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

---

## 坑 3：WSL 本体版本太旧，且 Store 连不上

**现象：** `wsl --list --online` 提示"必须更新到最新版本…按任意键安装"
**原因：** 系统自带的 WSL 是旧版；从 Microsoft Store 拉新包时连不上

**解决（关键）：**
```powershell
wsl --update --web-download
```
`--web-download` = 不走 Store，改从 GitHub Releases 拉 → **需要 github 可访问（本机靠加速器）**

**结果：** 装上 WSL 3.0.3.0，内核 6.18.54.1

---

## 坑 4：Linux 密码两次对不上

**现象：** `Sorry, passwords do not match` → `Authentication token manipulation error`

**原因：** **Linux 输密码时屏幕上什么都不显示**（没有星号、光标不动），
很容易以为没输进去，于是多按或重按。

**以后的做法：**
- 打一个简单密码（如 `leo123456`），两次一模一样
- 不看屏幕，打完直接回车
- 检查：CapsLock 关、NumLock 开、输入法切英文

**兜底（万一还是失败）：**
```powershell
wsl -d Ubuntu-24.04 -u root        # 用 root 进
adduser seeleo                      # 补建用户
usermod -aG sudo seeleo
wsl --manage Ubuntu-24.04 --set-default-user seeleo
```

## 装到 D 盘的正确姿势（本次成功的关键）

```powershell
mkdir D:\WSL -Force
wsl --install -d Ubuntu-24.04 --location D:\WSL\Ubuntu-24.04
```

**为什么要这样：** 默认 `ext4.vhdx` 落在 C 盘，装完 ROS2 会涨到 20–40 GB，
而且**长起来不会自己缩回去**。本机 C 盘只剩 30 GB。

**验证：**
```powershell
wsl -l -v                                              # VERSION 列必须是 2
Get-ChildItem D:\WSL -Recurse -Filter ext4.vhdx        # 应显示 1.39 GB
```

## 换源（装完立刻做）

```bash
sudo sed -i 's@//archive.ubuntu.com@//mirrors.tuna.tsinghua.edu.cn@g; s@//security.ubuntu.com@//mirrors.tuna.tsinghua.edu.cn@g' /etc/apt/sources.list.d/ubuntu.sources
sudo apt update && sudo apt upgrade -y
```

**顺序：先换源，再 update。** 反过来要多等十几分钟。
**实测速度：** 233 kB/s（清华源当晚偏慢，正常情况应更快）

## 给下次的我（三条）

1. **装 WSL 前先看 C 盘还剩多少**，低于 40 GB 就用 `--location` 装到别的盘
2. **报网络错先怀疑命令**，再看功能，最后才怪网络
3. **Store 连不上就走 `--web-download`**，但那条路要 github 通
