## 二、我整理的概念（不是面试原话）

### 柔顺控制是什么

**普通的位置控制：**

```
控制器命令：关节转到 30 度
机械臂就硬邦邦地往 30 度去，路上撞到什么也不管
→ 可能撞坏东西，也可能撞坏自己
```

**柔顺控制：**

```
机械臂表现得像一个【弹簧 + 阻尼】系统
你推它，它顺着你让一点；你放开，它回到目标位置
→ 人机协作安全，装配时能贴合而不是顶死
```

**四个常用方法（关键词，以后查）：**

| 方法 | 一句话 |
|---|---|
| **阻抗控制** Impedance Control | 让机械臂对外表现为一个指定的「质量-弹簧-阻尼」系统 |
| **导纳控制** Admittance Control | 由测到的力反推该走多远，输入是力、输出是位置 |
| **力位混合控制** Hybrid Force/Position | 某些方向控位置、某些方向控力（比如贴着墙擦） |
| **SEA 串联弹性执行器** | **硬件层面**的柔顺：电机和关节之间真加一个弹簧，靠测弹簧变形量算力 |

**最后一条最关键：柔顺有两条实现路子。**

```
软件柔顺：用力传感器 + 控制算法做出来（靠算）
硬件柔顺：靠 SEA 这种真的装了弹簧的结构做出来（靠机械）
```

**这就是为什么这个项目和机械专业有关**——硬件柔顺是纯机械设计问题
（弹性体尺寸、刚度、变形量测量），而它的效果又必须靠控制算法调出来。

### 双臂 + 移动，难在哪

| 难点 | 为什么 |
|---|---|
| **双臂协同** | 两只手搬同一个东西时，闭环不成立（互相推），必须做内力分配 |
| **底盘 + 机械臂耦合** | 底盘一动，臂的基座就变了，原来的轨迹控制全部失效 |
| **柔顺 + 移动叠加** | 底盘晃动会让柔顺控制误判为外力 |

**所以它是典型的「机械 + 控制 + 感知」三合一题目**，不是单纯机械或单纯算法。
